## 麻将建议的优先级

1. **先算向听**：同样向听时，比较有效进张数；进张多的形状优先。
2. **保留好形**：两面搭子 > 嵌张 > 边张；对子可作雀头或碰材。
3. **孤张先走**：没有同色相邻、没有对子、字牌孤张，通常先打。
4. **安全牌**：对手立直/副露后，优先打现物、筋牌和已经大量出现的字牌。
5. **不要只看一张**：打牌后仍要比较“下一巡的进张”和“放铳风险”。

## 扑克建议的优先级

1. **位置**：后位可以玩更宽的范围；前位收紧。
2. **起手牌结构**：对子、同花连张、大牌高张的价值不同。
3. **底池赔率**：跟注所需胜率 ≈ 跟注额 / (底池 + 跟注额)。
4. **听牌 outs**：转牌/河牌成牌概率约为 `outs × 2%`（转牌）或 `outs × 4%`（翻牌到河牌）。
5. **下注目的**：价值、诈唬、保护、控池，每次下注要能说清目的。
